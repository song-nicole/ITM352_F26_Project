Purpose of program:
We want to create a website that can help someone organize and plan their possible upcoming trip. Our goal is to create a webpage with a template that helps keep track and make decisions in the important aspects of planning the before, during, and after of each trip. This includes budget tracking, expense tracking, bill splitting, comparing flights and hotels, deciding on activities, and collaborating with others. The goal is to create something that will help guide the user in their decision making and to ensure that everything they need to plan and finish their trip is being kept in one place.


Main features:
- Budget Control: looks at your current plan versus the budget set for the trip and warns the user if they are going over budget
- Budget flexibility: asks the user if they have a strict or flexible budget and adjust accordingly
- Expense log: records how much money was spent and how much is left
- Bill splitting: splits the bill evenly among everyone in the group and tracks who paid and who didn’t
- Comparison: ability to compare prices for different things like hotels or flights
- Notes: notebook tab to add notes for tasks to complete later or something that might be nice to note down. (Also a place to store links and other miscellaneous things)
- Log-in: have users log in so that planners can be saved and reaccessed

Stretch Goals:
- Allow users to share plans and ideas with peers and let them make edits
- Allow users to mix and match tentative bookings and save them as different travel scenarios so that it is easy to go back and forth between plans.
- Allow users to customize what aspects or tools they want to see on their “travel board” (want to add a flights tab or remove it if it was a roadtrip.)
- Utilize APIs like SerpApi to extract flight and hotel information from certain websites

Program implementation:
For this project, we will apply different concepts we have learned in class to build our applications. Some libraries we plan to implement into the code will be PANDAS and JSON files. The plan is to first build a working model where the user can input budget information, log in, and have a notes area to highlight different ideas and notes. Then to start adding more features like the ability to compare different flight and hotel options to determine which choice is better suited for the user. We will also work to implement an API to provide users potential hotel and flight options to choose from.
